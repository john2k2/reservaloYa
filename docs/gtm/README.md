# Pack GTM — ReservaYa

Materiales listos para el lanzamiento público de [ReservaYa](https://reservaya.ar): turnos online para barberías y peluquerías que hoy operan por WhatsApp.

**Posicionamiento:** Dejá de perder clientes por WhatsApp. Tus clientes reservan online; vos recibís el turno confirmado y reducís las ausencias.

**Oferta:** 15 días gratis · USD 22/mes (transferencia en ARS o tarjeta vía Polar) · sin permanencia.

## Orden sugerido de publicación

1. **Capturas** — ver [SCREENSHOTS_CHECKLIST.md](./SCREENSHOTS_CHECKLIST.md); assets en [`assets/`](./assets/) (falta solo admin dashboard con login).
2. **Video** — grabar con [VIDEO_SCRIPT.md](./VIDEO_SCRIPT.md); usar las mismas URLs de la demo.
3. **LinkedIn** — publicar [LINKEDIN_POST.md](./LINKEDIN_POST.md) con video o carrusel de capturas.
4. **Piloto** — ejecutar [PILOT_ONBOARDING_15MIN.md](./PILOT_ONBOARDING_15MIN.md) con el primer negocio real.
5. **Cobro SaaS** — activar Polar/transfer con [POLAR_TRANSFER_ACTIVATION.md](../ops/POLAR_TRANSFER_ACTIVATION.md) antes de cobrar.
